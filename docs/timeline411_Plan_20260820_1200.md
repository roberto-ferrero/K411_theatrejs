# Plan de implementación de Timeline 411 HTML

Fecha: 2026-08-20 12:00 (Europe/Madrid)

## Objetivo

Crear Timeline 411 HTML como editor y runtime independiente de Theatre.js, pero
utilizando directamente el modelo JSON de Theatre.js 0.7.2. El JSON exportado debe
poder entregarse a `getProject(id, {state})` sin ningún adaptador.

## Decisiones aprobadas

- La primera entrega prioriza reproducción y visualización.
- La edición posterior incluye creación por doble click y borrado con `Delete`.
- La edición Bezier comienza mediante presets; graph editor y handles quedan fuera.
- La persistencia inicial es una descarga manual; no hay autoguardado.
- El estado inicial se carga desde `src/state.json`; la importación de archivos se
  pospone.
- La interfaz de usuario estará en español y la API conservará nombres ingleses.
- La selección inicial es individual.
- No se optimizan gestos táctiles en esta versión.
- Se añadirán tests automatizados compatibles con el stack actual.
- Sólo se monta una vista; la arquitectura permitirá varias vistas en el futuro.

## Requisitos ya establecidos

- Montaje dentro de `#timeline-411-html`.
- Contenedor dedicado y tamaño controlado por la aplicación anfitriona.
- `ResizeObserver` y superficie mínima de `640 × 240 px`.
- Scroll por debajo del mínimo.
- Árbol de tracks redimensionable entre 160 y 480 px, con máximo del 45 %.
- HTML, CSS y SVG; Shadow DOM desactivado.
- Modo Theatre.js conservado y modo WebGL inactivo.
- Estado visual separado del `TheatreProjectState` de animación.

## Arquitectura

```text
TheatreProjectState
        │
        ├─ TimelineStore ── comandos, transacciones, undo/redo
        ├─ Evaluator ────── tiempo → valores
        ├─ TimelinePlayer ─ clock → playhead
        ├─ Binding ──────── valores → Three.js
        └─ Projection ───── documento + viewport → render model
                                               │
                                               ▼
                                      HTML/SVG Renderer
```

## Fases

### 1. Modelo y validación Theatre 0.7.2

- Tipar `sheetsById`, static overrides, sequences, tracks y keyframes.
- Validar `definitionVersion`, IDs, tiempos, handles y valores serializables.
- Codificar property paths mediante `JSON.stringify(path)`.
- Mantener caches derivados fuera del documento serializado.

### 2. Runtime y bindings

- Evaluar tracks mediante búsqueda binaria.
- Implementar linear, hold, `connectedRight` y cubic Bezier.
- Crear player con play, pause, seek y loop.
- Registrar `Torus Knot` y aplicar rotation/wireframe a Three.js.

### 3. Store e historial

- Comandos para añadir, actualizar, mover y eliminar keyframes.
- Transacciones atómicas y gestos temporales.
- Undo/redo y revision history de hasta 50 revisiones.
- Eventos de documento, playback, selección, gestos e historial.

### 4. Proyección y GUI HTML/SVG

- Toolbar, árbol jerárquico, ruler, grid, filas, playhead y keyframes.
- Transformaciones tiempo↔píxeles y snapping a `subUnitsPerUnit`.
- `ResizeObserver`, scroll bajo threshold y divisor redimensionable.
- Clases CSS prefijadas `.k411-timeline-*`.

### 5. Edición inicial

- Click y drag del playhead.
- Selección individual.
- Drag horizontal de keyframes con snapping.
- Doble click para crear keyframes.
- `Delete` para eliminar y Escape para cancelar.
- Presets Linear, Hold, Ease, Ease In, Ease Out y Ease In Out.

### 6. Exportación

- Descargar `animation.json` con el esquema exacto Theatre 0.7.2.
- No incluir estado visual, bindings ni referencias DOM/Three.js.
- Generar IDs de revisión y conservar las últimas 50 revisiones.

### 7. Pruebas y verificación

- Tests de validación, easing, evaluación, snapping, comandos e historial.
- Test de carga de `src/state.json`.
- Test de exportación directa a Theatre.js 0.7.2.
- Verificación TypeScript y build de producción.

## Fuera de alcance

- Graph editor y edición manual de handles.
- Selección múltiple, clipboard y marquee.
- Importación de archivos y autoguardado.
- Optimización táctil.
- Markers, audio y event tracks.
- Vista WebGL y demostración simultánea de varias vistas.

## Criterio de finalización

Al seleccionar `Timeline 411 HTML`, el torus se reproduce sin cargar Theatre.js;
el usuario puede observar y recorrer sus tracks, mover/crear/eliminar un keyframe,
usar undo/redo, cambiar presets de interpolación y descargar un JSON que
Theatre.js 0.7.2 acepta directamente.

## Resultado de la ejecución

Implementación completada el 2026-08-20:

- Núcleo, store, evaluador, player, bindings, eventos y proyección separados del
  renderer.
- Vista HTML/SVG responsive montada en `#timeline-411-html`.
- Reproducción del torus sin cargar `@theatre/core` ni `@theatre/studio` en el
  modo Timeline 411 HTML.
- Selección, seek, drag con snapping, alta por doble click, borrado, presets,
  undo/redo y descarga de `animation.json`.
- Validación del esquema Theatre.js 0.7.2 y revision history limitada a 50 IDs.
- Tests de evaluación, store, player, proyección, API, vista HTML y carga directa
  del JSON exportado mediante `getProject(id, {state})`.
